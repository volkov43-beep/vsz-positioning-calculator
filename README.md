# ВСЗ — Калькулятор точности позиционирования станков с ЧПУ

Вятский станкостроительный завод готовит веб-калькулятор для обработки результатов испытаний отдельных осей станка с ЧПУ. Инженер-метролог, наладчик или специалист ОТК сможет ввести измеренные позиционные отклонения и получить показатели для протокола испытаний.

**Статус проекта — подготовка разработки.** Калькулятор пока не реализован. Согласованные материалы проекта и история изменений хранятся в этом репозитории.

## Какие задачи должна решать первая версия

| Элемент испытания | Предварительные границы |
| --- | --- |
| Объект | Одна линейная ось за испытание, ход до 2000 мм включительно |
| Наблюдения | Два направления подхода к каждой заданной позиции и пять повторений для каждого направления |
| Ввод | Заданные позиции и измеренные позиционные отклонения с указанием единиц и направления подхода. Число позиций зависит от применимой методики |
| Расчёт | Точность и повторяемость позиционирования, систематические отклонения и зона нечувствительности |
| Представление результатов | Таблицы, графики по оси и протокол испытания |

## Нормативная основа и границы применения

Исходный документ проекта — ГОСТ 27843–2006 (ИСО 230-2:1997) «Испытания станков. Определение точности и повторяемости позиционирования осей с числовым программным управлением». Проверка актуального статуса документа и применимости выбранной процедуры запланирована на итерацию 01А. После проверки будут уточнены условия испытаний и правила выбора позиций.

Первая версия ограничена показателями отдельной оси. Полная оценка пространственной точности станка выходит за эти границы. Калькулятор не заявляется как сертифицированное средство измерений. Достоверность результата зависит от методики испытания и качества исходных измерений.
