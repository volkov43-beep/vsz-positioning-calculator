# Автоматические тесты

Синтетические входы и независимые ожидаемые результаты для будущего ядра собраны в [пакете v1](fixtures/v1/README.md). Для автоматического обхода используй [манифест](fixtures/v1/manifest.json). В положительных файлах проверяются позиционные величины и все 12 итогов оси, в отрицательных — реакция на конкретный вход. Инструкции воспроизведения и единицы приведены в README пакета.

[Контрольный инструмент 06-1](verification/iteration-06/README.md) удостоверяет округление каждого вычисленного поля над точными binary64-входами. [Результаты и границы проверки](../docs/validation/06-reference-certification.md).

[Полная проверка этапа 06](verification/iteration-06/README.md#06-3-два-чистых-прогона) воспроизводит оба слоя, P05 до 10 000 позиций и ожидаемое исчерпание ресурса. [Инженерное заключение](../docs/validation/06-final-verification.md).
