## Сверка содержания и границ публикации

- С нормативной спецификацией 0.1 сопоставлены границы профиля, направления, число повторений и состав результатов. Для одной линейной оси с полным ходом до 2000 мм предусмотрены два направления, пять наблюдений на позицию в каждом направлении и 12 итоговых характеристик. Фиксированные 11 позиций относятся к исследованной книге. В профиле число позиций переменное.
- В документах согласованы единицы позиций и отклонений, направление вычитания для зоны нечувствительности и статус рекомендации по методу `sample-n-minus-1`. Минимальные синтетические наборы в спецификации предназначены для проверки формул. Новых процедур испытания при сверке не выявлено.
- В заключении PRO две константы вместо средних и пропуск наблюдения описаны раздельно. Четыре расхождения с печатной сводкой А.1 имеют отдельный статус. Пересчёты относятся к 02А. В 02Б проверялся перенос документации.
- В состав изменений входят только Markdown-файлы. Исходный PDF, книга Excel, внутренний подробный аудит и полные измерительные массивы в публикацию не включены.

## Проверки переноса

Обезличенное заключение совпадает с исходным файлом побайтово. В математической спецификации изменено только Markdown-оформление двух выражений. В §5 для оценки через размах добавлена защита встроенной формулы обратными кавычками, в §9.4 допуск сравнения оформлен блоком `math`. При прежнем оформлении GitHub показывал запятую на месте команды тонкого пробела. Содержимое самих выражений сохранено. SHA-256 оформленного для GitHub файла — `a3bcbc379030f5a54839a83aba82f73a9594f983694ae933b8b625b556cf29eb`.

Все 29 выражений после обработки Markdown на GitHub сверены с исходным TeX и отрисованы в SVG с помощью MathJax 3.2.2 без ошибок. В проверку вошли индексы, направления, модули и пределы экстремумов. Проверены обе таблицы формул в §5–6, единицы, внутренние ссылки, состав изменений и соответствие STATUS дорожной карте. Вычислительные тесты относятся к будущей программной реализации.
