## DEMO-08В. Комплект и репетиция

**Вердикт — показ директору можно провести на текущей сборке.** Проверенный путь — Chrome 156 на Linux x86_64, готовая статика или однофайловый HTML по локальному HTTP. На ноутбуке встречи владельцу остаётся проверить установку Node.js, масштаб и проектор. На Windows команды подготовлены для PowerShell. Отдельной проверки Windows, физического смартфона, Firefox, Edge и запуска через file:// в этой части не было.

Исходный main — `54b8ea6ad59dd483a77207453fa73c1da442cbda`, исходники проверенной сборки — [e53fb68bcc89d8de75b059684b30923349f116ee](https://github.com/volkov43-beep/vsz-positioning-calculator/commit/e53fb68bcc89d8de75b059684b30923349f116ee). Финальный коммит 08В добавляет проверочный комплект и инструкции в [тот же Draft PR №10](https://github.com/volkov43-beep/vsz-positioning-calculator/pull/10). Код интерфейса и ядра в этой части совпадает с e53fb68.
