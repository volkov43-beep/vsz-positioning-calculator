### Что вычисляется

Для каждой из двух серий реализованы μ, выборочная v, s, 2s, W, L, U и 4s. Дисперсия вычисляется через десять попарных квадратов с делителем 20. Тест отдельно сверяет её с точной центральной суммой квадратов с делителем 4. Из защищённых характеристик вычисляются ν, знаковая Bᵢ = μ↑ − μ↓, перекрёстный кандидат Cᵢ и Rᵢ. Все победители возвращаются в порядке `cross, up, down`. Линейные поля выражены в мкм, v — в мкм², заданная координата — в мм. [Определения](../methodology/math-spec.md) · [Ключи ответа](../architecture/data-model.md).

На синтетической позиции T06/p03 один выброс даёт μ↑ = 4 мкм, v↑ = 80 мкм², Bᵢ = +4 мкм. У Rᵢ определяющая ветвь ↑. [Команда запуска этого примера](../../src/README.md).

### Устройство модуля

| Область | Файл | Реализация |
| --- | --- | --- |
| Вход и режим | [contracts.ts](../../src/core/contracts.ts) | Снимок, версии, ключ попытки, цель research-demo, контракт полей |
| Нормализация | [input.ts](../../src/core/input.ts) | Исходная запись и единица, точный десятичный сдвиг мм → мкм, единственное округление, точные d, b и e, реестр коллизий в двух сериях |
| Точная арифметика | [rational.ts](../../src/core/rational.ts), [binary64.ts](../../src/core/binary64.ts) | Сокращённые дроби BigInt, целый корень, восстановление b по битам, деление с округлением ближайшего и чётностью при равенстве |
| Корневые выражения | [expression.ts](../../src/core/expression.ts) | Рациональные корни поглощаются, радикалы одного квадратного класса объединяются. Разные выражения сравниваются по включающим двоичным интервалам |
| Вычисление | [series.ts](../../src/core/series.ts), [position.ts](../../src/core/position.ts) | Точные локальные характеристики, ветви и независимое округление каждого поля. Защищённая позиция сохраняется для агрегации |
| Отказ | [diagnostics.ts](../../src/core/diagnostics.ts) | Причина, стадия, адрес, действие и связь с ключом попытки. Ошибки входа и вычислительные отказы получают разные состояния |

Для рационального результата ядро непосредственно формирует биты RN64 по целому частному и остатку. Для корневого выражения округляет обе точные внешние границы и принимает число только при совпадении их битов. Точное сокращение распознаёт равенство и истинный +0. Пределы уточнения — 128, 256, 512 и 1024 значащих бита. При исчерпании возвращается `failed/PRECISION_LOSS`. Проверка адресует операцию сравнения либо конкретное округляемое поле.

В десяти ожидаемых отказах основного корпуса пять позиций P02-offset-collapsed содержат коллизию d→b. Ещё на пяти позициях `ten-distinct-inputs` исходная ненулевая Bᵢ исчезает при десяти различных машинных входах. Экспериментальный модуль обнаруживает такой случай точным сопоставлением нулевых характеристик по d и b. Вне этих 306 вызовов отдельно проверены ошибочный ввод, неподдерживаемый выход и исчерпание ресурса.

### Ограничения и передача в 07-Д2

- Метод `sample-n-minus-1` предварительный. Бюджеты d→b по семействам открыты. Статус `budget-not-approved` сохраняется и при удостоверении всех полей второй ступени. Численных допусков для производственной выдачи прототип не назначает. [Открытые согласования ADR-0002](../decisions/ADR-0002-numerical-policy.md).
- Внутри одной позиции проверяются все десять наблюдений. Ненулевые исходные отклонения, исчезнувшие при переводе, коллизии и исчезновение исходной ненулевой позиционной характеристики блокируют выдачу. Для допуска по бюджету потребуются собственные границы на каждое семейство. Текущая выдача помечена `productionEligible: false`.
- У публичных чисел поддержаны математический ноль и конечный нормальный RN64. Допустимый ненулевой subnormal на **входе** сохраняет точное b. Отдельно ограничены длина исходной записи и модуль десятичного показателя — по 4096. Это технические пределы прототипа. Они не определяют область физической применимости испытания.
- Для 07-Д2 передаются `protectedPosition`, адреса повторов, трасса d→b и контракт отказа. Следующей части предстоят межпозиционные коллизии, выбор осевых экстремумов до округления, все 12 итогов и их независимая сверка. Вызывающий уровень отвечает за полный снимок испытания и SHA-256 его редакции. Пример Д1 изолирован до одной позиции.

**07-Д1 готова к проверке в общем Draft PR.** Экспериментальная 07-Д2 может продолжить эту ветку. Производственная реализация по-прежнему требует отдельного решения владельца и метролога.
