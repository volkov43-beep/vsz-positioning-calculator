## Что проверил PRO в 03А

Профиль — одна линейная ось, ход до 2000 мм включительно, по пять повторений в каждом направлении. Эталоны получены из десятичных строк с помощью рациональной арифметики и высокоточного извлечения корня. Независимый проверяющий скрипт использует попарные разности для дисперсии, отдельное выражение для двусторонней повторяемости и точные предикаты для равных экстремумов. Основание метода и определения показателей приведены в [математической спецификации 0.1](../methodology/math-spec.md).

Манифест осевых наборов содержит 28 меток сценариев. Дополнение P04 доводит общее число до 29. Одному сценарию могут соответствовать несколько файлов.

## Ограничение §9.2 и открытые решения

В фикстуре `P02-mixed-scale` у позиции `p02` эталонное поле `sd_up` равно 10⁻¹² мкм. В binary64 после вычитания общего якоря по §9.2 разброс теряется. Для оси эталон R = 4 × 10⁻¹² мкм, эксперимент по порядку 02А даёт ноль. Допуски §9.4 пропускают расхождение. Локальные критерии выявили 15 нарушений в этой фикстуре и 61 в отдельном опыте `EXP-P02-mixed-scale`. В проверенных опытах порядок с вычислением рассеяния внутри каждой серии прошёл локальные критерии. Эталонные числа и текст спецификации 0.1 сохранены.

Метод `sample-n-minus-1` (Q9 / D13), порядок вычислений, допуски для дисперсий, общие гарантии точности для A/E/M, шаг отображения и округление точных половин требуют согласования. Вопросы Q5 о знаке прибора, Q11 о происхождении и коррекциях реальных измерений и ограничения [области применения](../methodology/scope.md) остаются открытыми.
