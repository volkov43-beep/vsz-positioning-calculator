# Методика испытаний и расчёта

Раздел для согласованных границ применения стандарта и описания процедуры испытания. Для каждого показателя предстоит зафиксировать определение, ссылку на пункт документа, входные величины, единицы, направление подхода, знаки и правила округления.

Первый материал ожидается после 01А и согласования на перенос в 01Б. Описания готовятся своими словами. Исходный PDF стандарта хранится вне публичного репозитория.
