# MEETING-02Б. Браузерная приёмка планировщика

**Результат — PASS по 14 сценариям передачи MEETING-01.** Проверена локальная рабочая сборка React на синтетических данных. База main — `acbb10e5783508d65b0f0d2e3feb5e26c540cfd7`, исходная версия планировщика — `0b1e69943eda9c5e31d27859d4a0c10cb82a4191`. [Общий Draft PR №14](https://github.com/volkov43-beep/vsz-positioning-calculator/pull/14).

## Среда и способ проверки

Перед редактированием в настоящем браузере Chromium 158 проверены загрузка T06, счётчики 5/5 и 50/50, расчёт B = 4 и B̄ = 0,8 мкм. Итоговая проверка выполнена в **Google Chrome for Testing 158.0.8127.88, Linux, Headless Shell**, через Playwright. Проверялись события ввода и фокуса, текст формы, таблицы, SVG, состояние кнопок, текущая редакция, запросы страницы и фактически отрисованные кадры. Для прогона использована оптимизированная сборка, поданная по локальному HTTP. Публичный сайт ответил по HTTPS кодом 200 со сборкой main. Приёмка новой сборки по публичному адресу возможна после слияния.

Проверены ширины **1440, 1024, 768, 390, 360 и 320 CSS px**, также **320 px с корневым размером текста 200%**. На каждой ширине открыли учебный план, вызвали справку клавишей Enter, отредактировали координату с запятой, перешли клавишей Tab и повторно проверили интервалы. На 390/360/320 px с эмуляцией касаний применили план, проверили фокус у матрицы и ввели отрицательное измерение. Во всех семи режимах ширина прокрутки документа равнялась доступной ширине. У предложения из 64 строк проверена прокрутка внутри таблицы. Firefox, Edge, физический смартфон и оконный сеанс Chrome не проверялись.

## MEETING-02В — защита ручного редактирования позиций

На исходном HEAD `d31f435b7ef87d5fa2527941fe84cad2054c4ba9` в браузере воспроизведены оба обхода. У p03 в исходном T06 координата 500 мм. Прямая правка на 300 мм оставляла наблюдение ↑ №5 со значением 20 в этой же строке. После подтверждения «Удалить p03» исчезала вся строка. Редакция последовательно менялась с 1 на 2 и 3.

Исправление проверено на локальной production-сборке в Google Chrome for Testing 158.0.8127.88 (Headless Shell, Linux), на синтетических данных. В каждой проверке сохранности сверялись исходные строки в полях и номер редакции. Для рассчитанной T06 дополнительно сверены все итоги и реквизиты отчёта, включая SHA-256, а также отсутствие нового идентификатора запуска.
