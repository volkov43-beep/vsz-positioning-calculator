# Дорожная карта

Этап 00 создаёт основу репозитория. На этапах PRO и Chat Astra подэтап **А** проходит в соответствующем аналитическом чате. После утверждения результата подэтап **Б** выполняет Work Astra и передаёт материалы на проверку через Draft PR. Запись в GitHub ведёт Work.
