# Дорожная карта

Этап 00 создаёт основу репозитория. На этапах PRO и Chat Astra подэтап **А** проходит в соответствующем аналитическом чате. После утверждения результата подэтап **Б** выполняет Work Astra и передаёт материалы на проверку через Draft PR. Запись в GitHub ведёт Work. Этап 04 по заданию владельца разделён на четыре части с общей веткой и одним Draft PR. Все четыре части вошли в основную ветку через [PR № 5](https://github.com/volkov43-beep/vsz-positioning-calculator/pull/5). Этап 05 выполнен тремя частями 05-1–05-3 в одной ветке. Все три части объединены через [PR № 6](https://github.com/volkov43-beep/vsz-positioning-calculator/pull/6). [Отчёт этапа 04](iterations/04-product-ux.md) и [отчёт этапа 05](iterations/05-architecture.md).
