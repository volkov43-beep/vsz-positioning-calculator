# Архитектура

[Архитектура веб-калькулятора](architecture.md) описывает три варианта стека, компоненты MVP, проверку ядра по независимым эталонам, локальное хранение и статическое размещение. Для 05-1 рекомендован клиентский вариант с React, TypeScript и Vite. Статус решения — [ADR-0001, Proposed](../decisions/ADR-0001-application-architecture.md).

В 05-2 подготовлены [модель данных и формат файла испытания](data-model.md) и [контракты компонентов](contracts.md). В модели есть примеры черновика, наблюдений и сводки. В контрактах описаны диагностика N01–N10, устаревание результатов и восстановление после сбоя записи. Состояние трёх частей и исходная ревизия указаны в [отчёте итерации 05](../iterations/05-architecture.md).

[Архитектурное заключение 05-3](architecture-review.md) содержит [матрицу 23 требований MVP](architecture-review.md#2-покрытие-требований-mvp), исправленные расхождения и вердикт о готовности. В [плане реализации](implementation-plan.md) приведены [обязательная задача по численной политике и методу s](implementation-plan.md#обязательная-задача-pro-и-work), предложение по этапу 06, критерии этапов 07–14 и проверки безопасности и производительности.
