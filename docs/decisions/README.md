# Журнал решений

Здесь фиксируются решения, влияющие на методику, формат данных, архитектуру или область применения. Для каждой записи укажи вопрос, рассмотренные варианты, принятое решение, основание и ссылку на согласование. Открытые вопросы до принятия решения перечисляй в [STATUS](../STATUS.md).
