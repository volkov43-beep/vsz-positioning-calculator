# Проверка вычислений

В этом разделе будут храниться разрешённые к публикации контрольные наборы, результаты независимых расчётов и сравнения с эталонами. Для каждого набора указывают происхождение данных, единицы, ожидаемый результат и основание для допуска сравнения.

Пакет 03А содержит 53 синтетических осевых сценария и 12 отдельных примеров округления. [План проверок](reference-test-plan.md) описывает покрытие, а [манифест](../../tests/fixtures/v1/manifest.json) связывает каждый сценарий с проверенным JSON. Для воспроизведения используй [инструкцию пакета](../../tests/fixtures/v1/README.md).

[Заключение по численной политике](numerical-policy-review.md) рассматривает потерю локального разброса при общем центрировании и проверенные границы предложенной поправки. Заводские измерения и исходная книга Excel хранятся вне публичного репозитория.

[Обезличенное заключение по аудиту Excel](excel-audit-summary.md) — версия 0.1, итерация 02А. В разделе 5 описаны две константы вместо вычисляемых средних и отдельно разобран расчёт при пропущенном наблюдении. Раздел 7 посвящён расхождениям с печатным примером А.1. Основа для независимых контрольных наборов 03А приведена в разделе 9 заключения и разделе 12 [математической спецификации](../methodology/math-spec.md).

[Проверка численной политики PRE-06](pre06-numerical-policy-verification.md) связывает обе ошибки P02, новые контрпримеры локальному порядку, точные проверки округления и границы опубликованного предложения с решением о переходе к 06.

[Сертификация RN64 в 06-1](06-reference-certification.md) содержит результаты по 5 984 полям, адресам экстремумов и контрольным мутациям. [Команды воспроизведения](../../tests/verification/iteration-06/README.md).

[Входное представление и численные отказы в 06-2](06-input-loss-and-failures.md) охватывают 37 осевых наборов, аналитические границы ошибок, классы N01–N10 и семь диагностических мутаций.
