# Проверка вычислений

В этом разделе будут храниться разрешённые к публикации контрольные наборы, результаты независимых расчётов и сравнения с эталонами. Для каждого набора указывают происхождение данных, единицы, ожидаемый результат и основание для допуска сравнения.

Контрольные примеры готовятся на этапе 03. Заводские измерения и исходная книга Excel хранятся вне публичного репозитория.

[Обезличенное заключение по аудиту Excel](excel-audit-summary.md) — версия 0.1, итерация 02А. В разделе 5 описаны две константы вместо вычисляемых средних и отдельно разобран расчёт при пропущенном наблюдении. Раздел 7 посвящён расхождениям с печатным примером А.1. Основа для независимых контрольных наборов 03А приведена в разделе 9 заключения и разделе 12 [математической спецификации](../methodology/math-spec.md).
