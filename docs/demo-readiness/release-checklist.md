# Проверка перед показом директору

Пользуйтесь этим листом на том ноутбуке и проекторе, которые будут на встрече. Оставьте запас времени на один полный цикл и возврат к первому экрану. [Сценарий на 6 минут](director-demo-script.md) · [Запуск в PowerShell](runbook.md).

## До встречи

- [ ] Подключить питание, проверить проектор, мышь, клавиатуру и читаемость текста с места зрителя. Закрыть рабочие файлы, посторонние вкладки и уведомления.
- [ ] Скопировать и распаковать комплект на диск. Открыть локальные скриншоты и сценарий. На экране и в комплекте только синтетический T06.
- [ ] Проверить Node.js 24 и запуск Chrome. Сверить содержимое dist по SHA-256 из руководства.
- [ ] Запустить локальный сервер. Оставить его окно открытым. В Chrome видны заголовок калькулятора и полоса «Демонстрационный режим».
- [ ] Репетировать без доступа к интернету. Если предполагается использовать согласованный HTTPS-адрес, держать локальный комплект на том же ноутбуке.

## Один контрольный цикл

- [ ] «Загрузить пример T06» — пять позиций, 50 из 50 наблюдений. p03, 500 мм, ↑ №5 = 20 мкм.
- [ ] «Рассчитать» — видны 12 характеристик, B = 4 мкм и B̄ = 0,8 мкм. На графике выбрать p03, сверить исходный ряд ↑ и средние ↑/↓ = 4/0 мкм.
- [ ] «Изменить p03 ↑ №5» — заменить 20 на 0. В «Отчёт» видны «Данные изменены» и «Нет актуального результата».
- [ ] «К измерениям» → «Пересчитать» — все 12 итогов нулевые. У графика есть подпись о совпадении шести рядов на 0 мкм.
- [ ] В предварительном отчёте — редакция 2 при единственной замене, SHA-256, нулевой ряд p03 ↑, пометка о синтетических данных и ограничения метода.
- [ ] Восстановить T06 через «Начало» → «Загрузить пример T06» → «Подтвердить». В проверяемой ячейке снова 20. Вернуть первый экран для начала презентации.

## Резерв

- [ ] Закрыть тестовую вкладку и снова открыть локальный адрес. Пройти загрузку и первый расчёт на чистой копии. При предупреждении о потере данных завершить только демонстрационную копию.
- [ ] Держать под рукой восемь кадров ниже. Если на машине невозможно получить верный результат, продолжить по снимкам с явной оговоркой о записи репетиции. Для живого расчёта восстановить запуск по руководству.
