# DEMO-10 — проверка GitHub Pages после объединения

Использовать синтетические значения. Зафиксировать дату, браузер, merge SHA и ссылку на запуск.

- [ ] Найти в Actions запуск GitHub Pages на push в main с нужным SHA. Убедиться в успехе build и deploy. Открыть HTTPS-адрес из успешного deployment в новой вкладке.
- [ ] Проверить HTTP 200 для HTML, JS и CSS, правильный путь репозитория и доступность Web Crypto. Убедиться в наличии новой легенды, сводки наблюдений и отдельного счётчика координат.
- [ ] Открыть новую запись с семью позициями. Ввести шесть букв и две пятёрки. Ожидаются 2/70, 6 ошибок, 62 пропуска и 0/7 координат. Исправить букву по указанному адресу и проверить изменение счётчиков.
- [ ] Рассчитать T06 с 5/5 координат и 50/50 наблюдений. Проверить B = 4 мкм, B̄ = +0,8 мкм и 12 характеристик. Заменить p03 ↑ №5 на текст. Проверить ошибку, 49/50 и отзыв прежнего отчёта. Исправить на 0 и пересчитать. Проверить 12 нулей, совпадение шести рядов, новую редакцию и SHA-256 в отчёте.
- [ ] На 390, 360 и 320 px, в том числе при тексте 200% на 320 px, проверить карточку, 5 + 5 полей, переход к ошибке, ввод запятой и минуса, кнопку расчёта и график. Отдельно записать результат на физическом устройстве, если доступно.
- [ ] Во время ввода, расчёта и просмотра отчёта проверить журнал сети и URL на передачу измерений. Проверить предупреждение о демонстрационном режиме. Восстановить T06, перезагрузить вкладку и повторно открыть сайт. В обоих случаях должно открыться начальное состояние.
- [ ] Сообщить владельцу фактический HTTPS-адрес, проверенный SHA, результаты и пропущенные пункты.
